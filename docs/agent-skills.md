# 共有スキル

日本語を推敲する [yomiyasu](../.agents/skills/yomiyasu/SKILL.md) を `.agents/skills/yomiyasu/` に同梱しています。リポジトリ内でCodexを使うメンバーは、個人の環境へ追加インストールせずに同じバージョンを利用できます。

## 使い方

[AGENTS.md](../AGENTS.md) で、日本語の文章を作成・修正するときにyomiyasuを使うよう指示しています。応答・説明・文書・PR本文・レビュー・コメント・コミットメッセージに加え、コード変更後の作業報告も対象です。利用者が毎回スキル名を指定する必要はありません。

```text
README.mdの日本語を読みやすく整えてください。
専門用語・数式・実験条件・未確認事項の意味は変えないでください。
```

`$yomiyasu` と明示的に指定する方法も使えます。スキル本体は `AGENTS.md` で使用を求められた場合も明示的な依頼として扱います。この仕組みを使っているため、配布元のスキルを変更する必要はありません。フックは登録していません。

このルールはリポジトリの `AGENTS.md` を読むCodexに適用されます。変更を反映するには新しいセッションを開始してください。スキルが認識されない場合はCodexを再起動してください。

推敲では目視で原文と照合し、付属ツールで検査したあと、提出直前に最終稿と検査記録を照合します。検査を実行できなかった場合は、その理由を作業報告に記載します。

検査ツールにはPython 3を使います。Windowsでは `python` または `py -3` も利用できます。Pythonはこの外部スキルに付属する文章の検査専用であり、研究用プログラムの実装言語やビルド依存は変更しません。

検査時の記録は既定でリポジトリ直下の `.yomiyasu/` に保存され、ツールが作成する `.gitignore` でGit管理から除外されます。検査結果は意味の保持や読みやすさを保証するものではなく、原文との照合が必要です。
