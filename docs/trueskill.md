# TrueSkillの採用範囲と検証

[実装](../src/ratings/trueskill.cpp)は、[Herbrich・Minka・GraepelのNIPS 2006版](https://www.microsoft.com/en-us/research/wp-content/uploads/2007/01/NIPS2006_0688.pdf)の原版TrueSkillを1対1・引き分けなしへ限定したものです。§2の独立な正規事前分布とパフォーマンスモデル、§3・Table 1の切断正規分布の平均・分散への補正を使います。試合ごとにモーメントを一致させた正規分布を次の事前分布にします。多人数・チーム・引き分け・TrueSkill 2は対象外です。

## 初期値と定数

§4.2（PDFの7〜8ページ）の尺度を採用します。以下は標準偏差であり、分散として使うときは二乗します。

| 項目 | 値 | 原典との対応 |
| --- | --- | --- |
| 初期平均 `mu0` | 25 | 原典の `mu0` |
| 初期標準偏差 `sigma0` | 25/3 | 原典の `sigma0²=(25/3)²` |
| パフォーマンス標準偏差 `beta` | 25/6 | `beta=sigma0/2` |
| 動的変化の標準偏差 `tau` | 25/300 | `tau=sigma0/100` |
| 引き分け幅 | 0 | 引き分けなしの本実装での限定 |

`tau²` は対戦した2人の更新直前の分散に加えます。予測は保存済み状態の分布から計算するため、予測時に `tau²` は加えません。`beta` は生成器の `performance_std=1` とは尺度が異なります。固定能力の初期実験に対する `tau>0` を含め、正式な比較のパラメータはチームで確認します。ここで性能に合わせた調整は行っていません。

## 更新と予測

`mu` は推定平均、`sigma` は推定不確実性の標準偏差です。`s=+1` はAの勝利、`s=-1` はAの敗北、`phi`・`Phi` は標準正規分布の密度・累積分布です。§2–3のモデルを2人へ限定すると次の式になります。

```text
qa = sigmaA² + tau², qb = sigmaB² + tau²
c² = qa + qb + 2 beta², t = s (muA - muB) / c
v = phi(t) / Phi(t), w = v (v + t)
muA' = muA + s qa v / c, muB' = muB - s qb v / c
sigmaA'² = qa (1 - qa w / c²), sigmaB'² = qb (1 - qb w / c²)
P(A wins) = Phi((muA - muB) / sqrt(sigmaA² + sigmaB² + 2 beta²))
```

両者とも更新前の値から計算し、結果を検証してから同時に保存します。潜在能力、正解勝率、後続試合の結果は更新・予測へ使いません。

## 裾の数値計算

`Phi(t)=erfc(-t/sqrt(2))/2` を使います。大きな負の `t` では密度と累積分布がともに小さくなるため、[DLMF 7.9.1](https://dlmf.nist.gov/7.9.E1)を `z=y/sqrt(2), y=-t>0` へ変換した次の逆Mills比を使います。

```text
v(-y) = y + 1/(y + 2/(y + 3/(y + ...)))
f = 0; k=80,...,1 の順に f = k/(y+f)
v = y+f, w = v*f
```

`w` を `v*(v+t)` から計算し直さず、連分数の残り `f` を使って差し引きの桁落ちを避けます。理論上0〜1の `w` は丸め誤差をこの範囲へ収めます。切替条件 `t<-10` と打切り80段は本実装の数値計算上の選択であり、原論文が指定する定数ではありません。これらは下記の独立積分と照合します。任意の極端な入力に対する厳密な誤差上界を主張するものではありません。

## 独立した検証

[CTestの数値テスト](../tests/trueskill_tests.cpp)は以下を確認します。

- 初期状態の1勝後は、閉形式で `mu勝者=29.205473176557785`、`mu敗者=20.794526823442215`、双方 `sigma=7.1948164848133453`。許容絶対誤差は `1e-12`。
- 不均等な平均・分散について、更新式の `v`・`w` を使わず、正規事前分布と勝敗の尤度の積を直接積分する。標準化した能力を−10〜10でSimpson積分し、4,000分割と8,000分割を照合する。勝敗の両方向で各人の事後平均・標準偏差と予測勝率を比較し、許容絶対誤差は `1e-10`。
- `t=-9.999,-10,-10.001,-20,-1000` では、`u=y*(Z-y)` の密度に比例する `exp(-u-u²/(2y²))` を0〜60で20,000分割のSimpson積分により評価する。連分数を使わず切断正規分布のモーメントを得て、更新を絶対誤差 `2e-10` で照合する。
- 勝敗・プレイヤー順の反転、1万試合の有限性、CSV・評価時点・再現性・既存出力の保護を確認する。

これらはモデルと実装の整合性の検証であり、他手法より優れるという性能評価ではありません。
